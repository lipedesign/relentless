# Implementer

- Move issue `state:todo` → `state:in-progress`; assign worker.
- Implement against acceptance criteria; open PR linked to the issue.
- On ambiguity or risk: **human-gate** (decision-request template), not silent assumption.
- Before merge: **pr-merge-gate** skill.
- Authorship markers on all workflow comments.
